# SomethingOS

SomethingOS is a LineageOS-based Android ROM with a clean, monochrome,
dot-matrix-inspired look, built for tablets as well as phones. Under the
hood it's LineageOS; SomethingOS is a theming and UI layer on top.

SomethingOS is an independent community project. It is not affiliated with,
endorsed by, or based on software from Nothing Technology Limited, and it
does not ship any of Nothing's fonts, icons, wallpapers, sounds or other
assets.

> [!WARNING]
> **Not recommended for daily use.** It's in early development, built with
> heavy use of AI tools, and doesn't pass Play Integrity. See the
> [README](../README.md) for details.
